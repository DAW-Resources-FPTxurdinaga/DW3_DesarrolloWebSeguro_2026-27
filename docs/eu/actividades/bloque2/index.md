# 2. blokeko jarduerak

## Sarrera

Atal honetan moduluaren bigarren blokearekin lotutako jarduera praktikoak jasotzen dira.

Bloke honetan web aplikazio seguruagoak eraikitzea ahalbidetzen duten funtsezko mekanismoak aztertuko ditugu:

- Sarreren balidazioa.
- Erroen kudeaketa.
- Autentifikazioa.
- Baimen-kudeaketa.
- Sekretuen eta konfigurazioaren kudeaketa segurua.

Jardueren helburua kontzeptu horiek analisiaren, adibide praktikoen eta web garapen seguruarekin lotutako erronka txikien bidez aplikatzea da.

---

## Nola erabili jarduera hauek

Kapitulu bakoitzak zati teorikoan landutako edukiekin lotutako jarduerak ditu.

Jarduerak maila desberdinetan antolatuta daude:

### Adibide gidatua

Kontzeptu bat ulertzea ahalbidetzen du, pausoz pauso azalduko kasu baten bidez.

### TxurdiGest-era aplikatutako adibidea

Kapituluaren edukiak azterketa-kasu gisa erabilitako aplikazioaren barruko benetako egoerekin lotzen ditu.

### Egiaztatu ulertu duzula

Galderak eta egoera praktikoak biltzen ditu, kontzeptuen ulermena egiaztatzeko.

### Banakako jarduera

Analisi-, diseinu- edo inplementazio-lanak proposatzen ditu, modu autonomoan ebaztekoak.

### Lankidetza-tailerra

Erronka zabalago bat planteatzen du, taldean lankidetza-metodologia bati jarraituz lan egiteko.

---

## Eskuliburuarekiko lotura

Jarduerek kapitulu teorikoak osatzen dituzte.

Haien helburua hau da:

- Web garapen seguruko mekanismoak aplikatzea.
- Segurtasun-kontzeptuak benetako egoerekin lotzea.
- Analisi-gaitasuna garatzea.
- Garapen seguruaren pentsamoldea hartzea.

---

## Azterketa-kasua: TxurdiGest

Jarduerek **TxurdiGest** erabiliko dute erreferentzia-aplikazio gisa.

Kasu honen bidez web aplikazio bat ikuspegi desberdinetatik nola babestu aztertuko dugu:

- Aplikazioak jasotzen dituen datuak.
- Erroen kudeaketa.
- Erabiltzaileen identitatea.
- Baimenen kontrola.
- Barne-konfigurazioaren babesa.
