# 4. blokea. Hedapen segurua

Hedapen segurua aplikazio bat erabiltzaileentzat eskuragarri jartzeko azken etapa da, baina segurtasunaren ikuspegitik ere une kritikoa da. Ez da nahikoa aplikazioa funtzionatzea; modu kontrolatuan funtzionatu behar du, garapenean aurreikusi diren babes-erabakiak mantenduz.

Bloke honetan garatzaile web bati aplikazioa produkzio-ingurune batera prestatzeko beharrezkoak diren alderdi garrantzitsuenak landuko dira, segurtasuna ez galtzeko.

## Bloke honen helburua

- Produkzio-ingurunean aplikazioa modu seguruan konfiguratzeko ulertzea.
- Hedapenaren funtsezko puntuak ezagutzea: HTTPS, sekretuak, baimenak, esposizio-azalera, datu-basea eta logak.
- Garapen-webaren ikuspegia mantentzea, edukia sistema-administraziorako testuinguruan bihurtu gabe.
