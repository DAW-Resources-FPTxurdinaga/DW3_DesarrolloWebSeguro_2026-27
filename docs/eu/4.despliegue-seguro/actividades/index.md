# Jarduerak

Bloke honetako jarduera integratzailea garatutako proiektu bat berrikustea izan daiteke eta produkzioan hedapenerako segurtasun-hobekuntzak proposatzea.

## Proposamena

- Aplikazio baten konfigurazioa berrikusi.
- Babes osagarria behar duten puntuak identifikatu.
- Entregaren amaierako segurtasun-erabakiak justifikatu.
