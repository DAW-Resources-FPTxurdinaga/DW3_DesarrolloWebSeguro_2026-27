# Fitxategien eta direktorioen baimenak

Baimen okerrek fitxategi sentikorrak edo aplikazioaren karpetak atzitu nahi ez diren sarbideetara ireki ditzakete. Horregatik, hedapen segurua egin bitartean pribilegio minimoaren printzipioa kontuan hartu behar da.

## Printzipio nagusia

- Ez eman beharrezkoak ez diren baimenik.
- Mugatu idazketa eskubidea benetan behar duten direktorioetara.
- Babestu konfigurazio-fitxategiak eta baliabide sentikorrak.
