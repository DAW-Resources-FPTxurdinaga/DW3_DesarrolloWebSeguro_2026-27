# Segurtasun-buruzagiak

HTTP goiburu segurtasunak aplikazioaren babesa areagotu dezakete kodean aldaketa handirik egin gabe. Nabigatzaileek zein baliabide nola interpretatu behar dituzten eta zein ekintza onartzen dituzten kontrolatzen laguntzen dute.

## Ohiko goiburuak

- Content Security Policy (CSP)
- X-Content-Type-Options
- X-Frame-Options
- Referrer-Policy
