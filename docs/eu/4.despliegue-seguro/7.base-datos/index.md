# Datu-basea

Datu-basea aplikazioaren osagai funtsezko bat da eta produkzioan arreta berezia behar du. Sarbideak, kredentzialak eta konexioak garapen-inguruneak baino askoz kontrolatuagoak izan behar dira.

## Garrantzitsuak diren alderdiak

- Mantendu kredentzialak aplikazio bakoitzerako bereiziak.
- Murriztu sarbidea produkzio-inguruneetara.
- Babestu konexioak eta berrikusi babeskopiak.
