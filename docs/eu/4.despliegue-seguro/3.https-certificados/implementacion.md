# Inplementazioa

HTTPS behar bezala ezartzeko, ziurtagiri baliozko bat eta zerbitzariaren konfigurazio bat behar dira, konexio zifratuek erabilera behartzen dutela.

## Praktika gomendatuak

- Konfiantzazko ziurtagiriak erabili eta haien berritzea automatizatu, ahal denean.
- HTTP trafikoa guztia HTTPS-era birbideratu.
- Konexioak nabigatzaileetan eta garapen-tresnetan probatu.
- Ziurtagiriaren konfigurazioa aldian-aldian berrikusi.

## Garatzailearen ikuspegia

HTTPS ez da soilik azpiegituraren gaia. Aplikazioaren segurtasunaren parte ere bada, erabiltzaileari entregatzen zaion produktuaren barruan.
