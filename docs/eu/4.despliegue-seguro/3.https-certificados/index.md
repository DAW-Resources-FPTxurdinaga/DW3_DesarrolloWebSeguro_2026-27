# HTTPS eta ziurtagiriak

HTTPS webeko segurtasunaren oinarrietako bat da. Nabigatzailearen eta zerbitzariaren arteko komunikazioa babesten du eta datu sentikorrak, hala nola saioak edo kredentzialak, testu lauan bidai ez daitezen laguntzen du.

Produkzioan, HTTPS ez da aukera osagarria izan behar, baizik konfiantza eta segurtasunerako oinarrizko baldintza.

## Garrantzitsuak diren alderdiak

- HTTPS produkzioan beti aktibatu behar da.
- Ziurtagiriak segurtasunez eta garaiz berritu behar dira.
- HTTP-tik HTTPS-era birbideratzea eta HSTS bezalako mekanismoak erabiltzea babesa indartzen laguntzen du.
