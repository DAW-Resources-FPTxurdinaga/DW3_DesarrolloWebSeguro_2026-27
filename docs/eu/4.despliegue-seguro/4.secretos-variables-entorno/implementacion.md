# Inplementazioa

Sekretuak eta ingurune-aldagaiak integratzeko, hedapen bakoitzean estrategia argi eta errepikagarria jarraitzea garrantzitsua da.

## Praktika gomendatuak

1. Mantendu sekretu errealik ez duten adibide-fitxategi bat.
2. Erabili sekretuen kudeaketa-zerbitzuak ahal denean.
3. Mugatu balio sentikorrak atzitzeko sarbidea.
4. Beharrezkoa denean sekretuak aldian-aldian birsortu.

## Adibide sinplifikatua

```text
DB_HOST=prod-db.internal
DB_NAME=txurdigest
DB_USER=app_user
```

Sekretuak iturri kontrolatuetatik kargatu behar dira eta ez dira biltegian agerian uzten.
