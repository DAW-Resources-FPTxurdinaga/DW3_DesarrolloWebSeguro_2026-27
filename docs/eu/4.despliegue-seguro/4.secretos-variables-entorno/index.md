# Sekretuak eta ingurune-aldagaiak

Sekretuak eta ingurune-aldagaiak aplikazioaren konfigurazioa balio sentikorrengandik bereizteko funtsezkoak dira. Ingurune-aldagaiek parametro orokorrak zehazten dituzte normalean; sekretuek, aldiz, gakoa, pasahitza edo tokenak bezalako balioak izan ditzakete eta babestu egin behar dira.

Hedapen seguruan, sekretuen kudeaketa ez da ahaztu behar. Ez dira zuzenean kodean txertatu behar, ezta beharrezkoa ez denean partekatu ere.

## Oinarrizko printzipioak

- Ez gorde sekreturik zuzenean kodean.
- Mantendu sekretuak biltegitik kanpo.
- Erabili mekanismo seguruekin produkzio-inguruneetan kargatzea.
