# Zerbitzaria eta esposizio-azalera

Web zerbitzaria eta esposizio-azalerak zehazten dute aplikazioaren zein zatia dagoen kanpoalderako eskuragarri. Espozizioa handiagoa izatean, eraso-azalera ere handiagoa da.

Horregatik, hedapen seguruan gomendatzen da aktibatutako zerbitzuak mugatzea, beharrezkoak ez diren atariak itxita mantentzea eta soilik beharrezko baliabideak ikusgai uztea.

## Funtsezko kontzeptuak

- Esporatutako zerbitzu kopurua murriztea.
- Beharrezkoak ez diren atariak eta baliabideak itxita mantentzea.
- Sarbide-puntuak aldian-aldian berrikustea.
