# Web Garapen Segurua

Ongi etorri **Web Garapen Segurua** modulura, Web Aplikazioen Garapena (DAW) Goi Mailako Heziketa Zikloko ikasleentzat prestatutako materialera.

Dokumentazio hau web aplikazioak garatzeko orduan segurtasuna softwarearen bizi-ziklo osoan zehar kalitate-irizpidetzat txertatzeko gida gisa sortu da.

Ikastaroan zehar arriskuak identifikatzen, garapen-jardunbide egokiak aplikatzen, aplikazioak modu seguruan hedatzen eta analisi nahiz auditoria tresnen bidez haien segurtasuna egiaztatzen ikasiko duzu.

---

## Moduluaren helburuak

Modulu hau amaitzean gai izango zara:

- Web garapen seguruaren oinarrizko printzipioak ulertzeko.
- Aplikazioak diseinatzeko segurtasuna proiektuaren lehen faseetatik kontuan hartuta.
- Funtzionalitateak garatzeko programazio seguruko jardunbide egokiak aplikatuz.
- Hedapen-inguruneak segurtasun-irizpideekin konfiguratzeko.
- Web aplikazioak egiaztatzeko analisi eta auditoria tresnak erabiltzeko.
- Segurtasuna garatzaile baten eguneroko lanaren parte gisa integratzeko.

---

## Moduluaren antolaketa

Edukia bost bloketan antolatuta dago, web aplikazio baten bizi-zikloari jarraituz.

| Blokea | Edukia |
|---------|---------|
| 1 | Web garapen seguruaren oinarriak |
| 2 | Laborategiaren prestaketa |
| 3 | Web aplikazioen garapen segurua |
| 4 | Hedapen segurua |
| 5 | Auditoria eta etengabeko hobekuntza |

Bloke bakoitzean kontzeptuak, adibide praktikoak eta jarduerak lantzen dira, gero ikasturteko erronketan aplikatzeko.

---

## Lan-metodologia

Modulua **ETHAZI** metodologian integratuta dago. Horrenbestez, edukiak ez dira modu isolatuan lantzen; ikasitakoa pixkanaka aplikatuko da ikasturteko proiektuetan, Docker, DVWA, Burp Suite, OWASP ZAP eta AWS Academy oinarri dituen laborategi-ingurune batean.

Dokumentazio honek etengabeko kontsulta-gida gisa balioko du, baita erronketan hartutako erabaki teknikoak justifikatzeko erreferentzia gisa ere.

---

## Gomendioak

Blokeak proposatutako ordenan jarraitzea gomendatzen da, bakoitza aurrekoan eskuratutako ezagutzetan oinarritzen baita.

Kontzeptu batzuk hasieran teorikoak iruditu arren, guztiak berriro erabiliko dira aplikazio errealen garapenean, hedapenean eta auditorian.

!!! tip "Aholkua"

    Ez saiatu segurtasun-teknika guztiak buruz ikasten. Modulu honen helburua da ulertzea noiz, zergatik eta nola aplikatu behar diren aplikazio baten garapenean.
