# Inplementazio segurua

Bloke honetan aplikazio web baten diseinuan hartutako segurtasun-erabakiak kodean aplikatzen dira.

Helburua da datu sarrerak modu seguruan tratatzea, irteera egokiak sortzea, datu-basearen sarbidea babestea, erabiltzaileen identitatea eta baimenak kudeatzea, fitxategien karga kontrolatzea eta APIak konfigurazio seguruan garatzea.

Bloke osoan JavaScript eta PHP adibideak erabiliko dira, gaiaren arabera. Beharrezkoa izanez gero, ahultasunak dauzkaten inplementazioak ere aztertuko dira, zergatik huts egiten duten eta nola zuzentzen diren ulertzeko.
