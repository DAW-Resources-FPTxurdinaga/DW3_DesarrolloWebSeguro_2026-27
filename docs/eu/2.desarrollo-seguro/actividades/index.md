# 2. blokeko jarduerak

Jarduera hauek bloke honetan aztertutako kontzeptu nagusiak aplikatzeko dira, analisi eta diseinuko zeregin laburren bidez.

Helburua ez da teoria errepikatzea, baizik eta web aplikazio seguruak garatzeko erabakiak hartzen laguntzea eta erabaki horiek ikastaroaren erronkarekin lotzea.

- [2. jarduera. Aplikaziorako sarbidea diseinatzea](02-disenar-acceso-aplicacion.md)
- [3. jarduera. Konfigurazio seguru bat diseinatzea](03-disenar-configuracion-segura.md)
- [4. jarduera. Proiektuaren segurtasun-diseinua berrikustea](04-revision-diseno-seguridad.md)

!!! note

    Jarduera hauek laburrak dira, eta erronkaren garapenean egiteko pentsatuta daude, blokeko kontzeptuak benetako proiektu batean aplikatzen hasten direnean.
