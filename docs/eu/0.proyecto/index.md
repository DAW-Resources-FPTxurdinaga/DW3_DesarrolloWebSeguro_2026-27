# Erreferentziazko proiektua

Eskuliburu honetan **TxurdiGest** izeneko aplikazio bera erabiliko dugu kasu-azterketa gisa, web garapen seguruarekin lotutako kontzeptuak, adibideak eta jardunbide egokiak ilustratzeko.

Behin eta berriz erabilera isolatuko adibideak hartu beharrean, kapitulu guztiek aplikazio honi erreferentzia egingo diote, testuinguru komun bat mantentzeko eta segurtasun-mekanismo desberdinak ulertzea errazteko.
