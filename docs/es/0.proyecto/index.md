# Proyecto de referencia

A lo largo de este manual utilizaremos una aplicación denominada **TxurdiGest** como caso de estudio para ilustrar los conceptos relacionados con el desarrollo web seguro.

En lugar de utilizar ejemplos aislados, todos los capítulos harán referencia a esta aplicación, permitiendo mantener un contexto común y facilitar la comprensión de los distintos mecanismos de seguridad.
