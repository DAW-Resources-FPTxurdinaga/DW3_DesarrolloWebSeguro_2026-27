# Implementación segura

En este bloque se aplican al código las decisiones de seguridad definidas durante el diseño de una aplicación web.

El objetivo es implementar mecanismos que permitan tratar de forma segura los datos recibidos, generar salidas adecuadas, proteger el acceso a la base de datos, gestionar la identidad y los permisos de los usuarios, controlar la subida de archivos y desarrollar APIs con una configuración segura.

A lo largo del bloque se utilizarán ejemplos en **JavaScript** y **PHP**, según el problema tratado. Cuando sea necesario, también se analizarán implementaciones vulnerables para comprender por qué fallan y cómo corregirlas.
