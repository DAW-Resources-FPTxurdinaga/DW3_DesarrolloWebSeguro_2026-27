# Desarrollo Web Seguro

Bienvenido al módulo **Desarrollo Web Seguro** del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW).

Este material ha sido elaborado como guía de apoyo para el aprendizaje del desarrollo de aplicaciones web incorporando la seguridad como un criterio de calidad presente durante todo el ciclo de vida del software.

A lo largo del curso aprenderás a identificar riesgos, aplicar buenas prácticas de desarrollo, desplegar aplicaciones de forma segura y verificar su funcionamiento mediante herramientas de análisis y auditoría.

---

## Objetivos del módulo

Al finalizar este módulo serás capaz de:

- Comprender los principios fundamentales del desarrollo web seguro.
- Diseñar aplicaciones considerando la seguridad desde las primeras fases del proyecto.
- Implementar funcionalidades aplicando buenas prácticas de programación segura.
- Configurar entornos de despliegue con criterios de seguridad.
- Utilizar herramientas de análisis y auditoría para verificar aplicaciones web.
- Integrar la seguridad como parte del trabajo habitual de un desarrollador.

---

## Organización del módulo

El contenido se organiza en cinco bloques que siguen el ciclo de vida de una aplicación web.

| Bloque | Contenido |
|--------|-----------|
| 1 | Fundamentos del desarrollo web seguro |
| 2 | Preparación del laboratorio |
| 3 | Desarrollo seguro de aplicaciones web |
| 4 | Despliegue seguro |
| 5 | Auditoría y mejora continua |

Cada bloque combina conceptos, ejemplos prácticos y actividades que posteriormente se aplicarán durante el desarrollo de los retos del curso.

---

## Metodología de trabajo

El módulo se integra en la metodología **ETHAZI**, por lo que los contenidos no se estudian de forma aislada. Los conocimientos adquiridos se aplicarán progresivamente durante el desarrollo de los proyectos del curso, utilizando un entorno de laboratorio basado en Docker, DVWA, Burp Suite, OWASP ZAP y AWS Academy.

La documentación actúa como una guía de consulta permanente y como apoyo para justificar las decisiones técnicas adoptadas durante los retos.

---

## Recomendaciones

Esta documentación no está pensada únicamente para realizar una lectura lineal de principio a fin.

Durante el curso se indicarán los apartados que deben trabajarse en cada momento. Muchos de ellos volverán a consultarse durante el desarrollo de los retos.

Aunque algunos conceptos puedan parecer teóricos, todos volverán a utilizarse posteriormente durante el desarrollo, el despliegue y la auditoría de aplicaciones reales.

!!! tip "Consejo"

    No intentes memorizar todas las técnicas de seguridad. El objetivo del módulo es comprender cuándo, por qué y cómo deben aplicarse durante el desarrollo de una aplicación web.
