# Bloque 1. Fundamentos del desarrollo web seguro

Este primer bloque establece las bases conceptuales sobre las que se construirá todo el módulo. Antes de aprender a desarrollar aplicaciones web seguras, desplegarlas correctamente o realizar auditorías técnicas, es necesario comprender cómo funciona una aplicación web y cuáles son los principios que permiten desarrollar software más robusto.

La seguridad no comienza cuando aparece una vulnerabilidad, sino mucho antes, durante el análisis, el diseño y la implementación de la aplicación. Por ello, este bloque proporciona el lenguaje común y los conocimientos fundamentales que se utilizarán continuamente durante el resto del curso.

---

## Objetivos de aprendizaje

Al finalizar este bloque serás capaz de:

- Comprender qué significa desarrollar aplicaciones web seguras.
- Explicar cómo se estructura una aplicación web moderna.
- Entender cómo se comunican cliente y servidor mediante HTTP.
- Diferenciar cookies, sesiones, autenticación y autorización.
- Comprender la función de HTTPS y de los certificados digitales.
- Utilizar herramientas básicas para observar y analizar el tráfico HTTP.

## Relación con el resto del módulo

Los conocimientos adquiridos en este bloque serán la base para todo el curso.

- En el **Bloque 2** prepararás el entorno de laboratorio utilizando Docker, DVWA y Burp Suite.
- En el **Bloque 3** aplicarás estos conceptos al desarrollo seguro de aplicaciones web.
- En el **Bloque 4** aprenderás a desplegar aplicaciones con criterios de seguridad.
- En el **Bloque 5** utilizarás estas bases para analizar, verificar y mejorar la seguridad de los proyectos desarrollados durante el curso.

## Recomendaciones de estudio

Este bloque introduce numerosos conceptos que volverán a aparecer en diferentes momentos del módulo. No es necesario memorizar todos los detalles en una primera lectura; lo importante es comprender cómo se relacionan entre sí.

A medida que avances en el curso volverás sobre estos conceptos desde una perspectiva más práctica, aplicándolos durante el desarrollo de los retos y verificando su funcionamiento mediante herramientas de análisis y auditoría.
