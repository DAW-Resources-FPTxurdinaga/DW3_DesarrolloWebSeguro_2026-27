# Bloque 1. Fundamentos del desarrollo web seguro

Este bloque proporciona los conocimientos necesarios para comprender cómo funciona una aplicación web y por qué determinadas decisiones influyen en su seguridad.

Los conceptos estudiados servirán de base para el resto del módulo y se aplicarán posteriormente durante el diseño, la implementación, el despliegue y la verificación de aplicaciones web seguras.
