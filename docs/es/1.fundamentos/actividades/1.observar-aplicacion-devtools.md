# Actividad 1. Observar una aplicación web con DevTools

## Situación

Una aplicación web intercambia continuamente información entre el navegador y el servidor.

En esta actividad vas a observar esa comunicación utilizando las herramientas de desarrollo del navegador.

## Tu trabajo

Abre una aplicación web que utilices habitualmente y accede a las herramientas de desarrollo del navegador.

En Chrome o Chromium puedes abrirlas con:

```text
F12
```

o:

```text
Ctrl + Shift + I
```

### 1. Observa las peticiones HTTP

Abre la pestaña **Network** y recarga la página.

Localiza la petición correspondiente al documento principal y comprueba:

- el método HTTP utilizado;
- el código de estado recibido;
- el dominio al que se realiza la petición;
- si la comunicación utiliza HTTP o HTTPS.

Después, observa algunas de las peticiones realizadas para cargar recursos como:

- hojas de estilo;
- scripts JavaScript;
- imágenes;
- llamadas a una API, si existen.

!!! tip "Una pista"

    No es necesario analizar todas las peticiones. El objetivo es reconocer cómo el navegador solicita distintos recursos al servidor.

### 2. Observa las cabeceras

Selecciona una petición y abre la sección **Headers**.

Localiza algunos elementos que ya has estudiado, por ejemplo:

```text
Request Method
Status Code
Content-Type
User-Agent
```

No necesitas interpretar todas las cabeceras.

Comprueba simplemente que puedes distinguir entre información enviada por el navegador y la respuesta recibida del servidor.

### 3. Observa las cookies

Abre:

```text
Application → Cookies
```

Comprueba si la aplicación almacena alguna cookie.

Si existe una cookie relacionada con la sesión, observa si aparecen atributos como:

```text
Secure
HttpOnly
SameSite
```

No todas las aplicaciones utilizarán las mismas cookies ni tendrán exactamente la misma configuración.

### 4. Relaciona lo observado

Antes de cerrar DevTools, responde brevemente:

1. ¿Qué elementos de la arquitectura de una aplicación web has podido identificar?
2. ¿Qué información has podido observar sobre la comunicación HTTP?
3. ¿La aplicación utiliza HTTPS?
4. ¿Utiliza cookies? Si es así, ¿has podido identificar alguna relacionada con la sesión?
5. ¿Qué información has descubierto utilizando DevTools que normalmente permanece oculta al navegar por la aplicación?

No es necesario elaborar un informe. Una respuesta breve para cada cuestión es suficiente.
