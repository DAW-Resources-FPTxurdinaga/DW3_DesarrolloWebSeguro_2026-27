# Actividades del Bloque 1

## Introducción

En este apartado se incluyen las actividades prácticas asociadas al primer bloque del módulo.

A lo largo de este bloque hemos estudiado los fundamentos necesarios para comprender cómo funcionan las aplicaciones web y cómo se comunican sus diferentes componentes.

Las actividades tienen como objetivo aplicar estos conceptos mediante ejemplos, análisis y pequeños retos prácticos.

---

## Cómo utilizar estas actividades

Cada capítulo dispone de actividades relacionadas con los contenidos estudiados en la parte teórica.

Las actividades están organizadas en diferentes niveles:

### Ejemplo guiado

Permite comprender un concepto mediante un caso explicado paso a paso.

### Ejemplo aplicado a TxurdiGest

Relaciona los contenidos del capítulo con el caso de estudio utilizado durante todo el manual.

### Comprueba que lo has entendido

Incluye preguntas y situaciones prácticas para comprobar la comprensión de los conceptos.

### Actividad individual

Propone tareas de análisis o aplicación que deben resolverse de forma autónoma.

### Taller colaborativo

Plantea un reto más amplio para trabajar en equipo siguiendo una metodología colaborativa.

---

## Relación con el manual

Las actividades no sustituyen a los capítulos teóricos.

Su finalidad es:

- Aplicar los conceptos aprendidos.
- Relacionar teoría y práctica.
- Desarrollar la capacidad de análisis.
- Acercar el aprendizaje a situaciones reales de desarrollo web.

---

## Caso de estudio: TxurdiGest

Muchas de las actividades estarán relacionadas con **TxurdiGest**, la aplicación utilizada como hilo conductor del manual.

A través de este caso práctico analizaremos cómo aplicar buenas prácticas de desarrollo web seguro en un entorno cercano a la realidad profesional.
