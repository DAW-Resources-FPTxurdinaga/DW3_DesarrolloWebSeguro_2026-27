# Actividades del Bloque 1

Las actividades de este bloque están orientadas a observar cómo funciona una aplicación web y relacionar los conceptos estudiados con el desarrollo de los retos.

Se proponen únicamente dos actividades breves:

1. [Observar una aplicación web con DevTools](1.observar-aplicacion-devtools.md)
2. [Aplicación rápida al reto](2.aplicacion-reto.md)

La segunda actividad puede realizarse cuando el equipo comience a definir la arquitectura de su proyecto.
