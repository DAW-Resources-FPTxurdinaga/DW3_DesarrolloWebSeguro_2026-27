# Resumen de trabajo - 20-07-2026

## 1. Objetivo general del proyecto

Construir unos apuntes bilingues (es/eu) para el modulo optativo de Desarrollo Web Seguro en DAW, con enfoque de desarrollo seguro integrado en el flujo real de trabajo (no enfoque de pentesting).

Principios acordados:

- Organizacion por flujo de desarrollo, no por lista de vulnerabilidades.
- Metodologia: comprender -> analizar -> detectar -> corregir -> aplicar al reto ETHAZI -> desplegar -> verificar.
- DVWA como laboratorio base en reto 1.
- Casos propios Laravel/Vue para reto 2.
- Contenido breve, tecnico y accionable.
