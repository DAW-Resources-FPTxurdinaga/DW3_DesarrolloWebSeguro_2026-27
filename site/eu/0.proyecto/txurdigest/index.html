    TxurdiGest: eskuliburuaren kasu-azterketa¶

    Sarrera¶

    Eskuliburu osoan aplikazio bera erabiliko dugu hari gidari gisa, web garapen seguruarekin lotutako kontzeptuak, adibideak eta jardunbide egokiak azaltzeko.

    TxurdiGest izena du aplikazio horrek, eta Lanbide Heziketako ikastetxe baterako kudeaketa-sistema integrala irudikatzen du.

    Helburua ez da hutsetik aplikazio oso bat garatzea, baizik eta liburuko adibide guztiak testuinguruan jartzeko aukera emango duen eszenatoki komun bat izatea. Horrela, irakurleak segurtasunarekin lotutako alderdiak ulertzean zentratu ahal izango du arreta, aplikazio desberdinetara etengabe egokitu beharrik izan gabe.

    Zer da TxurdiGest?¶

    TxurdiGest hezkuntza-zentro baten eguneroko kudeaketa errazteko sortutako web aplikazioa da.

    Plataforma bakar batetik informazio akademikoa administratu, erabiltzaileak kudeatu, ordutegiak kontsultatu, kalifikazioak erregistratu eta administrazio-lan ugari egin daitezke.

    Edozein web aplikazio moderno bezala, TxurdiGestek informazio sentikorra gordetzen du eta hainbat erabiltzaile-motek erabiltzen dute; beraz, segurtasuna bere funtsezko eskakizunetako bat da.

    Aplikazioaren helburuak¶

    TxurdiGestek, besteak beste, honako prozesu hauek kudeatzeko aukera ematen du:

    • Ikasleen kudeaketa.
    • Irakasleen kudeaketa.
    • Administrazio-langileen kudeaketa.
    • Ziklo formatiboen eta moduluen kudeaketa.
    • Matrikulak.
    • Ordutegiak.
    • Kalifikazioak.
    • Atazen entrega.
    • Irakasleen eta ikasleen arteko komunikazioa.
    • Dokumentazio akademikoaren kontsulta.

    Sistemak funtzionalitate asko izan arren, eskuliburu honetan segurtasun-kontzeptuak azaltzeko beharrezkoak direnak soilik erabiliko ditugu.

    Sistemaren erabiltzaileak¶

    TxurdiGestek hainbat erabiltzaile-profil ditu, bakoitza bere baimen espezifikoekin.

    Profila Funtzio nagusiak
    Administratzailea Sistema konfiguratu eta baliabide guztiak administratzen ditu.
    Irakaslea Taldeak, jarduerak eta kalifikazioak kudeatzen ditu.
    Ikaslea Informazio akademikoa kontsultatu eta atazak entregatzen ditu.
    Administrazio-langilea Matrikulak, espedienteak eta dokumentazioa kudeatzen ditu.

    Erantzukizunen banaketa horrek autentifikazioa, baimen-kudeaketa eta sarbide-kontrola bezalako kontzeptuak aztertzea ahalbidetuko du.

    Kudeatzen den informazioa¶

    Aplikazioak oso informazio askotarikoa gordetzen du.

    Beste datu batzuen artean, honako hauek aurki ditzakegu:

    • Datu pertsonalak.
    • Helbide elektronikoak.
    • Pasahitzak.
    • Matrikulak.
    • Espediente akademikoak.
    • Kalifikazioak.
    • Ordutegiak.
    • Administrazio-dokumentazioa.
    • Ikasleek bidalitako fitxategiak.

    Informazio hori guztia behar bezala babestu behar da datuen konfidentzialtasuna, osotasuna eta erabilgarritasuna bermatzeko.

    Zergatik erabili kasu-azterketa bakarra?¶

    Liburu tekniko askok proiektu bera erabiltzen dute obra osoan zehar.

    Metodologia horrek abantaila ugari ditu:

    • Adibideen ulermena errazten du.
    • Kapitulu bakoitzean testuingurua errepikatzea saihesten du.
    • Aplikazio bereko osagai ezberdinak nola eboluzionatzen diren behatzea ahalbidetzen du.
    • Itxuraz independenteak diren kontzeptuak lotzen laguntzen du.
    • Ikaskuntza ingurune profesional batera hurbiltzen du.

    Eskuliburu honetan, adibide guztiak TxurdiGestekin lotuta egongo dira.

    TxurdiGest eta segurtasuna¶

    Segurtasunaren ikuspegitik, TxurdiGestek erakutsiko du nola garatu behar den web aplikazio bat egungo jardunbide egokiak jarraituz.

    Eskuliburuak aurrera egin ahala, honako alderdi hauek nola babestu ikusiko dugu:

    • Sarreren balidazioa.
    • Erroreen kudeaketa.
    • Autentifikazioa.
    • Baimen-kudeaketa.
    • Saioen kudeaketa.
    • Ohiko erasoen aurkako babesa.
    • APIen garapen segurua.
    • Zerbitzariaren konfigurazio segurua.

    Helburua izango da ulertzea ez soilik zein mekanismo dauden, baizik eta baita zergatik diren beharrezkoak eta nola inplementatu behar diren ere.

    DVWArekiko lotura¶

    Eskuliburuaren lehen blokeetan TxurdiGest soilik erabiliko dugu.

    Geroago DVWA (Damn Vulnerable Web Application) agertuko da, ahultasunak aztertzeko bereziki diseinatutako aplikazioa.

    Bi aplikazioek funtzio desberdinak baina osagarriak betetzen dituzte:

    Aplikazioa Helburua
    TxurdiGest Jardunbide egokiak jarraituz aplikazio seguruak garatzen ikastea.
    DVWA Benetako ahultasunak aztertzea eta aplikazio bat behar bezala garatzen ez denean nola ustiatu daitezkeen ulertzea.

    Konbinazio horri esker, garapen segurua eta nahita ahula den beste bat etengabe alderatu ahal izango dira.

    Erabilitako teknologiak¶

    Beharrezkoa denean adibide praktikoak erakusteko, TxurdiGestek web garapen modernoan oso erabilitako teknologia multzo bat erabiliko du.

    Eskuliburu osoan zehar, batez ere honako hauetan oinarritutako adibideak agertuko dira:

    • HTML5.
    • CSS.
    • JavaScript.
    • PHP.
    • Laravel.
    • MySQL.
    • HTTP eta HTTPS.
    • API RESTak.

    Hala ere, aztertutako segurtasun-kontzeptuak teknologia horietatik independenteak dira eta edozein garapen-ingurunetan aplika daitezke.

    Ideia nagusiak¶

    • TxurdiGest izango da eskuliburu osoan erabiliko den kasu-azterketa.
    • Hezkuntza-zentro baten kudeaketa-web aplikazioa irudikatzen du.
    • Adibide guztiek testuinguru funtzional bera partekatuko dute.
    • Aplikazioak garapen segurua ikuspegi errealista batetik aztertzea ahalbidetuko du.
    • Geroago DVWArekin osatuko da ahultasunak eta erasoak aztertzeko.
