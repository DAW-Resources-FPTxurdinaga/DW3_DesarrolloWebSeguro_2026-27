    1. blokea. Web garapen seguruaren oinarriak¶

    Lehen bloke honek modulu osoaren oinarri kontzeptualak ezartzen ditu. Web aplikazio seguruak garatzen, modu seguruan hedatzen edo auditoria teknikoak egiten ikasi aurretik, beharrezkoa da web aplikazio baten funtzionamendua eta garapen segurua ahalbidetzen duten oinarrizko printzipioak ulertzea.

    Segurtasuna ez da ahultasun bat agertzen denean hasten; askoz lehenago hasten da, aplikazioaren analisi, diseinu eta garapen faseetan. Horregatik, bloke honek ikastaro osoan zehar erabiliko diren kontzeptuak eta hizkuntza tekniko komuna aurkezten ditu.

    Ikaskuntza-helburuak¶

    Bloke hau amaitzean gai izango zara:

    • Web aplikazioak modu seguruan garatzea zer den ulertzeko.
    • Web aplikazio moderno baten arkitektura azaltzeko.
    • Bezeroaren eta zerbitzariaren arteko komunikazioa HTTP bidez nola egiten den ulertzeko.
    • Cookieak, saioak, autentifikazioa eta baimentzea bereizteko.
    • HTTPS eta ziurtagiri digitalen funtzioa ulertzeko.
    • HTTP trafikoa behatzeko eta aztertzeko oinarrizko tresnak erabiltzeko.

    Blokearen edukiak¶

    Blokea honako orrialde hauetan antolatuta dago:

    1. Web garapen seguruaren sarrera
    2. Web aplikazio baten arkitektura
    3. HTTP protokoloa
    4. Cookieak, saioak eta egoeraren kudeaketa
    5. HTTPS eta ziurtagiri digitalak
    6. Web analisi tresnak
    7. Blokearen laburpena

    Orrialde bakoitzak funtsezko kontzeptu bat garatzen du, eta kontzeptu horiek berriro erabiliko dira laborategietan, erronketan eta aplikazioen hedapenean.

    Moduluarekiko lotura¶

    Bloke honetan eskuratutako ezagutzak izango dira ikastaro osoaren oinarria.

    • 2. blokean, laborategiko ingurunea prestatuko duzu Docker, DVWA eta Burp Suite erabiliz.
    • 3. blokean, kontzeptu hauek web aplikazioen garapen seguruan aplikatuko dituzu.
    • 4. blokean, aplikazioak segurtasun-irizpideekin hedatzen ikasiko duzu.
    • 5. blokean, oinarri hauek erabiliko dituzu garatutako proiektuen segurtasuna aztertzeko, egiaztatzeko eta hobetzeko.

    Ikasteko gomendioak¶

    Bloke honek modulu osoan zehar berriro agertuko diren kontzeptu ugari aurkezten ditu. Ez da beharrezkoa lehen irakurketan xehetasun guztiak buruz ikastea; garrantzitsuena kontzeptuen arteko loturak ulertzea da.

    Ikastaroan aurrera egin ahala, kontzeptu horiek ikuspegi praktikoago batetik landuko dituzu, erronken garapenean aplikatuz eta analisi nahiz auditoria tresnen bidez egiaztatuz.

    Aholkua

    Jarraitu orrialdeak proposatutako ordenan. Kapitulu bakoitzak hurrengoetan erabiliko diren kontzeptuak aurkezten ditu, eta laborategiak nahiz erronkak ulertzea erraztuko dizu.
