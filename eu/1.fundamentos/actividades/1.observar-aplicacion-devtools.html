    1. jarduera. Web aplikazio bat DevTools-ekin behatzea¶

    Egoera¶

    Web aplikazio batek etengabe trukatzen du informazioa nabigatzailearen eta zerbitzariaren artean.

    Jarduera honetan komunikazio hori behatuko duzu nabigatzailearen garapen-tresnak erabiliz.

    Zure lana¶

    Ireki ohikoan erabiltzen duzun web aplikazio bat eta sartu nabigatzailearen garapen-tresnetan.

    Chrome edo Chromium-en honela ireki ditzakezu:

    F12

    edo:

    Ctrl + Shift + I

    1. Behatu HTTP eskaerak¶

    Ireki Network fitxa eta berriz kargatu orria.

    Kokatu dokumentu nagusiari dagokion eskaera eta egiaztatu:

    • erabilitako HTTP metodoa;
    • jasotako egoera-kodea;
    • eskaera zein domeinutara egiten den;
    • komunikazioak HTTP edo HTTPS erabiltzen duen.

    Ondoren, begiratu baliabideak kargatzeko egindako eskaera batzuk, adibidez:

    • estilo-orriak;
    • JavaScript scriptak;
    • irudiak;
    • API batera egindako deialdiak, halakorik badago.

    Pista bat

    Ez da beharrezkoa eskaera guztiak aztertzea. Helburua da nabigatzaileak zerbitzariari baliabide desberdinak nola eskatzen dizkion identifikatzea.

    2. Behatu goiburuak¶

    Hautatu eskaera bat eta ireki Headers atala.

    Bilatu jada ikasi dituzun elementu batzuk, adibidez:

    Request Method
Status Code
Content-Type
User-Agent

    Ez duzu goiburu guztiak interpretatu behar.

    Egiaztatu besterik ez duzu egin behar nabigatzaileak bidalitako informazioa eta zerbitzariak itzulitako erantzuna bereizteko gai zarela.

    3. Behatu cookieak¶

    Ireki:

    Application → Cookies

    Egiaztatu aplikazioak cookieren bat gordetzen duen.

    Saioarekin lotutako cookieren bat badago, behatu agertzen diren atributuak, adibidez:

    Secure
HttpOnly
SameSite

    Aplikazio guztiek ez dituzte cookie berak erabiliko, eta ez dute zertan konfigurazio bera izan.

    4. Lotu behatutakoa¶

    DevTools itxi aurretik, erantzun labur:

    1. Web aplikazio baten arkitekturako zer elementu identifikatu ahal izan dituzu?
    2. Zer informazio behatu ahal izan duzu HTTP komunikazioari buruz?
    3. Aplikazioak HTTPS erabiltzen al du?
    4. Cookieak erabiltzen al ditu? Hala bada, saioarekin lotutako baten bat identifikatu ahal izan duzu?
    5. Zer informazio aurkitu duzu DevTools erabilita, normalean aplikazioa nabigatzean ezkutuan geratzen dena?

    Ez da txostenik egin behar. Galdera bakoitzerako erantzun laburra nahikoa da.
